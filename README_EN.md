## 🧠 Description
**LYNK25** is an advanced web dashboard for monitoring and managing **P25 reflectors**.

It provides real-time system visibility, including traffic, connected stations, transmission history, and usage statistics. It also includes modern features such as activity ranking, geolocation mapping, and automated notifications.

This project is inspired by the open work of **Jonathan Naylor (G4KLX)**, **DVReflector by NØSTAR**, and the global digital radio community.

As with my previous projects, the visual identity and concept are inspired by my family — this version is dedicated to my wife **Jocelyn**, thank you for your constant support ❤️

## 🚀 Features

- 📡 **Real-time reflector monitoring**
- 👥 **Live connected stations list** (highlights newest 🆕)
- ⚙️ **Configuration management** (.ini, IP settings)
- 🔄 **Service control & server reboot**
- 📜 **Transmission history with filters**
- 🏆 **Activity ranking + Top 3 podium**
- 🗺️ **User map (RadioID + location)**
- 📲 **Telegram notifications & logs**
- 🎨 **Full customization without coding**
- ℹ️ **About page (credits & version)**
- 🔄 **Version check system**

---

## 🌍 Integrations

- **DVReflector API** → reflector status  
- **RadioID API** → user data (name, city)  
- **Telegram API** → alerts & notifications
